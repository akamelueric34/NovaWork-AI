# NovaWork AI: Workplace Productivity Assistant

## Project Overview
NovaWork AI is a web application designed to help professionals reclaim their workday. Built with a premium, dark-mode SaaS aesthetic, this unified dashboard allows users to choose a focused assistant and turn rough inputs into useful, editable work. The application simulates AI generation to showcase practical prompt engineering workflows, emphasizing user-friendly design and strict adherence to ethical AI practices.

## Features Implemented
The application integrates four core AI-powered productivity tools:
*   **Smart Email Generator:** Designed to draft polished workplace emails in any tone.
*   **Meeting Notes Summarizer:** Built to turn transcripts into clear decisions and action items.
*   **AI Research Assistant:** Provides summaries, insights, and recommendations.
*   **AI Chatbot:** An interactive assistant configured to get practical workplace guidance.
