# NovaWork AI: Workplace Productivity Assistant

## Project Overview
NovaWork AI is a web application designed to help professionals reclaim their workday. Built with a premium, dark-mode SaaS aesthetic, this unified dashboard allows users to choose a focused assistant and turn rough inputs into useful, editable work. The application simulates AI generation to showcase practical prompt engineering workflows, emphasizing user-friendly design and strict adherence to ethical AI practices.

## Features Implemented
The application integrates four core AI-powered productivity tools:
*   **Smart Email Generator:** Designed to draft polished workplace emails in any tone.
*   **Meeting Notes Summarizer:** Built to turn transcripts into clear decisions and action items.
*   **AI Research Assistant:** Provides summaries, insights, and recommendations.
*   **AI Chatbot:** An interactive assistant configured to get practical workplace guidance.

## UI/UX & Responsible AI
*   **Dashboard Layout:** Features a fixed left sidebar for seamless navigation between the dashboard and individual tools.
*   **Interactive Launchpad:** The main workspace utilizes clean, descriptive cards for immediate access to each assistant.
*   **Built-in Safeguards:** A persistent "Responsible AI" disclaimer is anchored in the navigation sidebar, explicitly reminding users that "AI outputs are suggestions and require human review.
*   **Frictionless Access:** Operates completely on the frontend with no login, database, or authentication requirements, ensuring immediate access.

## Technologies and Tools Used
*   **Frontend Framework:** React / Tailwind CSS (Generated via Lovable AI)
*   **Architecture:** Frontend-only prototype (No backend or database)
*   **AI Integration:** Simulated via client-side mock data to demonstrate functionality without live API constraints
*   **Version Control:** GitHub

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/akamelueric34/NovaWork-AI.git
```

### 2. Open the Project

```bash
cd NovaWork-AI
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Open the local development URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## Usage

1. Open the application.
2. Select a tool from the sidebar.
3. Enter your information or question.
4. Submit the request.
5. Review the AI-generated response.

---

No account or registration is required.
